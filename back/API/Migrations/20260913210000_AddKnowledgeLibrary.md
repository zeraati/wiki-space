# توضیح migration کتابخانه دانش

این migration ساختار دیتابیس مورد نیاز کتابخانه دانش را ایجاد می‌کند. جدول `Subject` برای اطلاعات پایه موضوع، جدول `Knowledge` برای رکورد اصلی دانش و جدول `KnowledgeTag` برای تگ‌ها ساخته می‌شوند.

در جدول `Knowledge` برای موضوع و ایجادکننده کلید خارجی وجود دارد. در جدول تگ، کلید خارجی `KnowledgeId` با حذف cascade تعریف شده است؛ بنابراین تگ‌ها بدون باقی‌ماندن داده یتیم همراه دانش حذف می‌شوند.

ایندکس ترکیبی `KnowledgeId` و `Name` از ثبت دوباره یک تگ برای یک دانش جلوگیری می‌کند. متد `Down` عملیات برعکس را انجام می‌دهد و جدول‌ها را حذف می‌کند؛ معمولاً در محیط واقعی rollback migration باید با احتیاط انجام شود.
